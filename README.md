# Prime Snack

**Alumno:** José Eduardo Miranda Valderrama

Proyecto desarrollado para la materia Aplicaciones Web 1 de la carrera Analista en Sistemas del IES 21.

PrimeSnacks es un e-commerce orientado a la venta de snacks proteicos y saludables, como barritas, bites, galletitas, snacks crocantes y premezclas.
