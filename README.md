# Prime Snack

**Alumno:** José Eduardo Miranda Valderrama

Proyecto desarrollado para la materia Aplicaciones Web 1 de la carrera Analista en Sistemas del IES 21.

Prime Snacks es un prototipo de tienda de barritas y snacks de proteína vegetal de Córdoba.

## Entrega M2

Abrí `index.html` en el navegador o usá Live Server desde la raíz del repositorio. El sitio usa HTML y una hoja de estilos CSS compartida. La portada y Barritas muestran el mismo producto como ejemplo y Otros snacks reserva su espacio para futuros productos.

Para probar los formularios de ingreso y registro, completalos con datos de prueba. El navegador valida los campos y muestra una confirmación de demostración sin enviar sus valores.
